## 5. Explain What Happens After Entering a URL

When we enter a URL in a web browser, the browser first uses DNS (Domain Name System) to find the IP address of the server hosting the website. Then, the browser sends a request to that server to access the webpage. The server responds by sending the required website files, such as HTML, CSS, JavaScript, and images. The browser reads the HTML to understand the structure of the page, uses CSS to style it, and executes JavaScript to add functionality and interactivity. Finally, the browser combines these resources and renders the webpage on the screen so that the user can view and interact with it.
